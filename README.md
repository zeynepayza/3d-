# Trilocale · 3D Tur

Bir Milano dairesinin 3D modelinde scroll ile gezilen web sayfası (Vite + Three.js + GSAP).

- Aşağı kaydırdıkça kamera eve yaklaşır, tavan kesilir ve odalar sırayla gezilir.
- Eşyalara tıklayarak, işaretlerden ya da sağdaki listeden odaklanılır; odakta fareyle döndürüp yakınlaştırılabilir. `Esc` tura döner.

## Çalıştırma

```bash
npm install
npm run dev
```

Duraklar ve metinler: `src/tour.js` · Sahne ve kamera: `src/main.js`
